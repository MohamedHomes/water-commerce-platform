# Design System Foundation

## Brand Direction

AquaFlow is an original water commerce platform with a clean, trustworthy, and premium visual identity. The design system is deliberately distinct from commodity market clones and is built around freshness, clarity, and operational confidence.

## Accessibility

- minimum contrast and focus states
- touch targets sized for mobile use
- layout works with Arabic RTL and English LTR
- no hard-coded strings in interface surfaces

## Localization

The interface uses localization resources rather than embedded strings for both Arabic and English.
