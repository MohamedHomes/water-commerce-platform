# Accessibility Requirements

## Standards

- support screen readers with semantic labels
- ensure touch targets are large enough for mobile ordering
- maintain readable contrast ratios
- keyboard and assistive technology compatibility for admin portal
- support focus states and error messaging clarity
- ensure localization does not break layout or directionality

## Language support

The app supports Arabic RTL and English LTR without hard-coded strings or layout assumptions.

## Visual accessibility

- maintain accessible status colors with text labels
- avoid relying on color only for meaning
- optimize spacing for legibility and scanning
- ensure order status, promotions, and errors remain understandable for all users
