# Information Architecture

## Primary user flows

- browse products
- search and filter catalog
- select variant and quantity
- add to cart
- checkout with address and delivery options
- review and pay
- track order
- support and profile management

## Core global navigation

- home
- categories
- search
- favorites
- cart
- orders
- profile

## Product information model

- brand
- product
- variant
- price
- package size
- availability
- warehouse delivery zone context

## Content model

The information architecture separates catalog entities from pricing and availability to support multiple cities, delivery zones, and product variants without flattening the data model.
