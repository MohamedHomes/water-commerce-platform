# Components

## Core components

- primary and secondary buttons
- quantity selectors
- product cards
- price badges
- chips and filters
- section headers
- bottom sheets
- order status tiles
- delivery progress cards
- address selection cards
- empty state illustrations and copy
- loading skeleton cards

## Design patterns

- high-contrast mobile cards
- strong pricing hierarchy
- simple, readable action states
- delivery status with clear semantic colors
- summary blocks before final payment

## System guidance

Components should remain consistent across both Arabic and English screens, while allowing automated RTL flipping where supported by the platform.
